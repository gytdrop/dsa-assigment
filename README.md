# dsa-assigment


The following programs are included in this collection:

Recursive Fibonacci Series: Generates the Fibonacci series up to N terms using a recursive function.

Recursive Factorial: Computes the factorial of a given number using recursion.

Array Operations: A menu-driven program to perform insertion, deletion, and traversal in a one-dimensional array.

Binary Search: Implements the Binary Search algorithm to find an element in a sorted array.

Bubble Sort: Sorts an array using Bubble Sort and displays the array state after each pass.

Insertion Sort: Implements the Insertion Sort algorithm.

Merge Sort: Sorts an array using the Merge Sort algorithm (Recursive implementation).

2D Array Addressing: Calculates the memory address of an element in a 2D array using Row-Major and Column-Major formulas.

Stack (Array Implementation): Implements a stack using static arrays with Push, Pop, Peek, and Display operations.

Stack (Linked List Implementation): Implements a stack using dynamic memory allocation (Linked List).

Queue (Array Implementation): Implements a queue using static arrays with Enqueue, Dequeue, Peek, and Display operations.

Queue (Linked List Implementation): Implements a queue using dynamic memory allocation.

Queue using Two Stacks: Implements a queue data structure by utilizing two stacks.

Singly Linked List (Insertion): Creates a linked list and inserts nodes at the beginning, middle, and end.

Singly Linked List (Deletion): Deletes a node from a linked list based on a specific value or key.

Binary Tree Representation: Demonstrates how to represent a binary tree using an array.

Tree Traversals: Performs Preorder, Inorder, and Postorder traversals of a binary tree.

Max Heap: Builds a Max Heap from an array and performs the heapify operation.

Graph Adjacency Matrix: Represents an undirected graph using an Adjacency Matrix.

Graph BFS: Performs Breadth-First Search (BFS) traversal on a graph.

How to Run

You can compile these programs using any standard C++ compiler (like GCC).

Example:

g++ "1. Recursive generation of Fibonacci series up to N terms.cpp" -o output
./output


Requirements

C++ Compiler (g++, clang, etc.)
